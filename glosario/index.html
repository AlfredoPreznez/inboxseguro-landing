Glosario de correo y DNS

Definiciones verificables de RBL, MX, BIMI, MTA-STS, RUA, selector DKIM, política y alineación DMARC para responsables de empresas.

RBL (lista negra de correo)

Una RBL (Realtime Blackhole List o lista negra de correo) es un listado público de direcciones IP o dominios asociados a envío abusivo…

Registro MX

Un registro MX (Mail Exchanger) es un registro DNS que indica el nombre de host que acepta correo para un dominio, junto con una prioridad…

BIMI

BIMI (Brand Indicators for Message Identification) es un mecanismo que permite a los receptores mostrar el logo de una marca en mensajes…

MTA-STS

MTA-STS (SMTP MTA Strict Transport Security) es un mecanismo (RFC 8461) con el que un dominio receptor declara que acepta SMTP sobre TLS…

RUA (reportes agregados DMARC)

RUA (Reporting URI for Aggregate reports) es la etiqueta DMARC que indica a dónde enviar reportes agregados periódicos sobre resultados…

Selector DKIM

Un selector DKIM es un nombre corto que subdivide el espacio de claves públicas de un dominio.

Política DMARC (none / quarantine / reject)

La política DMARC (etiqueta p=) indica a los receptores qué se sugiere hacer con mensajes que fallan la evaluación DMARC.

Alineación DMARC
